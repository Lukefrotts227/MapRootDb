MapRootDb

An in-memory Rust database built around a Node/Structure DAG model, with bincode persistence and a TCP protocol/server.

What is this?

MapRootDb is a small database engine written in Rust. Data is organized as a directed acyclic graph of Node objects held inside a Structure, giving each record explicit parent/child relationships rather than a flat table layout. The Database can hold multiple structures at once, and everything can be serialized to disk with bincode and reloaded later. A simple TCP protocol and server expose the database over the network so clients can connect and issue commands directly.

Build & install

git clone https://github.com/Lukefrotts227/MapRootDb
cd MapRootDb
cargo build --release
cargo run

Requires a working Rust toolchain (cargo included).
